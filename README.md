# Учебный пульс

Учебный веб-сервис для планирования задач и отслеживания прогресса. Данные задач сохраняются локально в браузере.

## Что было сделано

- Создан адаптивный интерфейс на HTML и CSS для добавления учебных задач.
- Реализованы приоритеты, отметка выполнения, удаление и фильтрация задач.
- Добавлены статистика, прогресс и сохранение данных в `localStorage`.
- Реализовано отображение текущей версии из `release.json` для проверки обновлений.
- Приложение упаковано в Docker-контейнер с Nginx и заголовками безопасности.
- Добавлен endpoint проверки состояния `/health` и Docker healthcheck.
- Выполнена локальная проверка: образ успешно собран, конфигурация Nginx валидна, страница отвечает `200`, `/health` возвращает `ok`, контейнер имеет статус `healthy`.
- Создан Git-репозиторий на ветке `main`; проект зафиксирован в коммитах и отправлен в репозиторий GitHub.
- Подготовлено описание выполненной работы и ограничений на использование проекта.

## Лицензия и ограничения

Проект создан исключительно для сдачи домашнего задания. Любое его использование, в том числе коммерческое или некоммерческое, запрещено.
